# Linear Programming Solver — Aplicação Interativa em Python

Aplicação desenvolvida em **Python** e **Streamlit** para visualização e resolução de problemas de **Programação Linear (PL)** através do **Método Gráfico** (para 2 variáveis) e do **Método Simplex** (para $n$ variáveis com variáveis de folga).

---

## 🚀 Como Executar o Projeto

1. **Ative o ambiente virtual:**
   ```bash
   source venv/bin/activate
   ```

2. **Instale as dependências:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Inicie a aplicação:**
   ```bash
   streamlit run main.py
   ```

4. Acesse no navegador em `http://localhost:8501`.
